# csv_pdf_build

林地台帳レイヤ + リレーションされた Excel(林地台帳詳細・森林簿詳細)を検索し、該当する林地台帳を**地図として印刷(PDF出力)**する QGIS プラグイン。

## インストール
`csv_pdf_build/` フォルダを QGIS のプラグインフォルダにコピー(またはzip化して「ZIPからインストール」)し、プラグイン管理で有効化。

## 事前準備
1. 林地台帳レイヤと、Excel(林地台帳詳細・森林簿詳細など)を QGIS に読み込む
2. プロジェクト > プロパティ > リレーション で、林地台帳(親)→各 Excel(子)のリレーションを作成(完了済みならそのまま)

## 使い方
メニュー「プラグイン > 林地台帳 CSV/PDF 出力」
1. 「2. 検索レイヤ選択」でリレーション済みのレイヤを選ぶ(通常は自動)。リレーション先は自動検出されます。データは事前に読み込まず、検索のたびに必要な分だけ読みます
2. 「1. 検索」で検索するレイヤを選ぶ。初期値は「すべてのレイヤを横断」で、氏名などを入れると親とリレーション先すべてから探します。親だけ・特定のリレーション先だけに絞ることもできます。条件は複数追加可(AND)、全角半角・大小文字は区別しません
3. 出力する項目にチェック(レイヤごとのタブ。CSV の列と PDF の情報欄に使います)
4. 表の行を選択(未選択なら全件)して「4. 出力」で PDF 出力または CSV 出力。リレーション先を検索した場合は「一致したレコードのみ」に絞って出力できます

- 日付検索: 項目を選び「(日付) 以降/以前/と同じ」を指定。令和6年4月1日・令6.4.1・R06.04.01・令和六年四月一日・令和060401・2024-04-01・Excel のシリアル値(46160)などの形式を日付として比較します(期間は「以降」と「以前」の2条件)
- 親レイヤの行で表示: リレーション先(氏名・更新日など)で検索しても、結果を林地台帳の行で表示(一致件数つき)
- 地図で選択 / 選択して拡大: 検索結果の林地台帳を QGIS 上で選択(表の行を選べばその行だけ)
- 表と地図の連動: 表で選んだ行の筆と施業班を地図でも選択。「全選択」「選択クリア」は表と地図の両方に効きます
- 検索クリア: 検索条件・期間・結果の表を空に戻します(地図の選択はそのまま)
- 期間指定: 日付項目と開始日・終了日(和暦可)で絞り込み。項目は検索するレイヤに関係なく全レイヤから「レイヤ名: 項目名」で選べます(既定は林地台帳マスターの「現_届出」)。氏名は先頭の条件行が既定

## 保存先
「3. 出力」の「保存先」でフォルダを指定すると、PDF・CSV の保存ダイアログがそのフォルダで開き、ファイル名はタイトルから自動で入ります(例: 林地台帳 ina2026002.pdf)。所有者別PDFはフォルダを聞かずにそのまま保存します。最後に保存した場所を覚えていて、QGIS を再起動しても引き継ぎます

## 地図PDF
検索結果の林地台帳を、QGIS の印刷レイアウトで地図にして PDF に出力します(現在の地図キャンバスで表示中のレイヤが対象)。
- 対象の筆は黄色の塗りと赤い枠で強調し、地図ラベルに選んだ親レイヤの項目(地番など)を表示。周囲の筆も見える範囲にズーム
- 重ねる図形: 施業班などの図形レイヤを選ぶと、キー(例: 施業班の KEY_02 = 林地台帳の 施業KEY)が一致する地物を青で一緒に描き、凡例を付けます。施業班も入る範囲にズームし、「地図で選択」では両方を選択します(既定は名前に「施業班」を含むレイヤ。リレーションの設定は不要)
- 地図の範囲: 「1筆ごとに1ページ」または「検索結果をまとめて1ページ」。用紙は A4 横/縦、縮尺は自動(1:1,000・1:2,500 など切りのよい値に切り上げ)または 1:◯◯ を指定
- ページ下の情報欄に【変更林地】【林地台帳】【森林簿 INAKEY】を表示(森林簿は INAKEY の値だけを重複なしで表示。オフにもできます)。まとめページは【変更林地一覧 (N 件)】として所在KEY を並べ、入りきらない分は「…他 N 件」
- タイトル: 1筆ごとは「林地台帳」、まとめページは届出番号(1つならその番号、複数なら ina2026001〜ina2026043 (43 件))。凡例は「林地」「森林」
- 印刷プレビュー → PDF: プリンタを使わず1ページずつ表示(先頭10ページのみ描画)。保存は全ページ
- PDF 出力: 全ページを1つの PDF に保存
- 所有者別PDFを作成: 所有者の項目(リレーション先の氏名など)で分け、フォルダに「所有者名.pdf」を1人1ファイルで作成
- 所有者別PDFで「届出番号」(林地台帳マスターの Excel に入力した ina2026001 などの番号)を選ぶと、届出ごとに「ina2026001.pdf」を作ります(タイトルは「林地台帳 ina2026001」で氏名は入れません。番号の無いものは出力しません)
- 所有者別PDFを月ごとのフォルダに分ける: チェックすると「令和8年4月/ina2026001.pdf」のように、届出日(期間指定で選んだ日付の項目)の月ごとのフォルダに保存します。日付が読めないものは「日付不明」フォルダ

## CSV 出力
「3. 出力する項目」でチェックした項目を列にして保存します(見出しは「変更林地:所在KEY」「林地台帳:届出番号」「森林簿:INAKEY」など)。1 筆に森林簿などが複数あるときはその件数分の行になり、林地の項目は各行に繰り返します。文字コードは UTF-8 (BOM付き・Excel向け) / UTF-8 / Shift_JIS から選べます

## テスト
- 通常: `python3 -m unittest discover -s tests`(QGIS 不要。QGIS 用のテストは自動でスキップ)
- QGIS 込み: `QT_QPA_PLATFORM=offscreen /usr/bin/python3.12 -m unittest tests.test_qgis_integration`(python3-qgis が必要。検索 → 地図 → PDF を通しで実行)
