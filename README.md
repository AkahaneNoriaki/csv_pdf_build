# csv_pdf_build

林地台帳レイヤ + リレーションされた Excel(林地台帳詳細・森林簿詳細)を検索し、CSV / PDF に出力する QGIS プラグイン。

## インストール
`csv_pdf_build/` フォルダを QGIS のプラグインフォルダにコピー(またはzip化して「ZIPからインストール」)し、プラグイン管理で有効化。

## 事前準備
1. 林地台帳レイヤと、Excel(林地台帳詳細・森林簿詳細など)を QGIS に読み込む
2. プロジェクト > プロパティ > リレーション で、林地台帳(親)→各 Excel(子)のリレーションを作成(完了済みならそのまま)

## 使い方
メニュー「プラグイン > 林地台帳 CSV/PDF 出力」
1. 「2. 検索レイヤ選択」でリレーション済みのレイヤを選ぶ(通常は自動)。リレーション先は自動検出され、親と一緒に読み込まれます(進捗バー表示)。データを更新したら「データ再読込」
2. 「1. 検索」で検索するレイヤを選ぶ。初期値は「すべてのレイヤを横断」で、氏名などを入れると親とリレーション先すべてから探します。親だけ・特定のリレーション先だけに絞ることもできます。条件は複数追加可(AND)、全角半角・大小文字は区別しません
3. 出力する項目にチェック(レイヤごとのタブ)
4. 表の行を選択(未選択なら全件)して CSV 出力 / PDF 出力。リレーション先を検索した場合は「一致したレコードのみ」に絞って出力できます

- 日付検索: 項目を選び「(日付) 以降/以前/と同じ」を指定。令和6年4月1日・R6.4.1・2024-04-01 の形式を日付として比較します(期間は「以降」と「以前」の2条件)
- 親レイヤの行で表示: リレーション先(氏名・更新日など)で検索しても、結果を林地台帳の行で表示(一致件数つき)
- 地図で選択 / 選択して拡大: 検索結果の林地台帳を QGIS 上で選択(表の行を選べばその行だけ)
- CSV: 林地台帳の1件につき、詳細・森林簿の多い方の件数だけ行を出力(親の項目は繰り返し)。文字コードは UTF-8(BOM付)/UTF-8/Shift_JIS
- PDF: 林地台帳1件=1ページ(A4)。日本語フォントは選択可能

## テスト
`python3 -m unittest discover -s tests`(検索・CSV・HTML生成ロジックのみ。QGIS不要)
